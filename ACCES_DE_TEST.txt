4. INSTALLER CE JEU DE TEST SUR LE SERVEUR (LWS / cPanel)
================================================================================

Se placer dans le dossier de l'application, puis :

  cd ~/gestionsites            # ou le chemin reel de votre installation
  git pull
  composer install --no-dev --optimize-autoloader
  php artisan migrate --force

  # ATTENTION : la commande suivante EFFACE TOUTE LA BASE avant de la recreer.
  # A n'utiliser que sur une base de test, jamais sur des donnees reelles.
  php artisan migrate:fresh --seed --force

  php artisan optimize:clear

Si la base contient deja des donnees que vous voulez garder, n'utilisez PAS
migrate:fresh. Utilisez seulement :

  php artisan migrate --force
  php artisan db:seed --force      # n'ajoute que ce qui manque, ne recree rien

4 bis. LE COURRIEL DE BIENVENUE
================================================================================

A chaque creation d'acces, le titulaire recoit un courriel : entete au logo de
L'Artisan, message de bienvenue, et pied aux coordonnees de DC-KNOWING. Il ne
contient JAMAIS le mot de passe — celui-ci se remet de vive voix.

Pour qu'il parte reellement, le serveur doit etre configure. Dans le .env :

  MAIL_MAILER=smtp
  MAIL_HOST=mail.votredomaine.com      # SMTP fourni par LWS
  MAIL_PORT=465
  MAIL_USERNAME=contact@votredomaine.com
  MAIL_PASSWORD=...
  MAIL_ENCRYPTION=ssl
  MAIL_FROM_ADDRESS=contact@votredomaine.com
  MAIL_FROM_NAME="L'Artisan Automobile"

Puis : php artisan config:clear

Tant que MAIL_MAILER=log, aucun courriel ne part : il est seulement ecrit dans
storage/logs/laravel.log. C'est le reglage actuel en developpement.

Pour tester l'envoi une fois configure, creer un acces avec votre propre adresse.

  par superviseur / responsable de site / commercial, avec objectifs remis a zero.

  deroulante « Commercial » serait vide et plus aucune saisie ne serait possible.
